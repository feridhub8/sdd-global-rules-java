Rules that apply to all of my Java projects. Every AI assistant session must read these files before doing any work.

| File | Covers |
|---|---|
| [collaboration.md](collaboration.md) | How the assistant works with me |
| [workflow.md](workflow.md) | Spec-driven development with OpenSpec |
| [git.md](git.md) | Commits, branches, pushes, ignored files |
| [java.md](java.md) | Java stack, build, code style |

| [testing.md](testing.md) | Automated tests, written with each feature |
| [graphify.md](graphify.md) | When and how to use Graphify |

Project-specific constraints go in that project's `openspec/config.yaml`, not here.

These rules grow with my projects. When a project settles something that applies to all Java projects, propose adding it here.
